# Portfolio Pro

This is a lightweight portfolio website built with HTML and CSS (no JavaScript required for core interactions).

[View here](https://bati58.github.io/portfolio-/)

## Overview
- Responsive portfolio with sections: Home, About, Skills, Projects, Services, Contact, and UI/UX gallery.
- Uses CSS patterns for interactions (modals and toggles) and a dotted animated background.

## Run locally
Open `index.html` in a browser, or serve with a simple HTTP server for best results:

Python 3:

```powershell
python -m http.server 8000
# then open http://localhost:8000
```

Or use VS Code Live Server extension.

## Development
- Edit `index.html`, `style.css`, and assets in `assets/`.
- No build step required.
