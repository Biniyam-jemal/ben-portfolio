# Biniyam Portfolio

[View here](https://Biniyam-jemal.github.io/ben-portfolio/)

This is a personal portfolio website for Biniyam, built as a responsive front-end project using HTML, CSS, and JavaScript. It showcases skills, featured projects, services, and contact options in a clean single-page layout.

## Overview

The portfolio is designed to present Biniyam as a frontend developer growing into full-stack development. It includes:

- A hero section with intro text, typing animation, and quick actions
- About, skills, projects, services, and contact sections
- Dark and light theme toggle with saved preference
- Responsive navigation for desktop and mobile
- Contact and hire request forms powered by Web3Forms
- Smooth scrolling and active section link highlighting

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Font Awesome
- Google Fonts
- Web3Forms

## Getting Started

Because this is a static website, no build step is required.

1. Clone or download the project.
2. Open `index.html` in your browser.

If you want a better local development workflow, you can run it with a simple local server such as VS Code Live Server.

## Customization

To personalize or improve the portfolio, update these areas:

- `index.html` for text content, links, and project details
- `style.css` for colors, layout, animations, and responsive styling
- `script.js` for theme toggle, typing effect, navigation behavior, and form handling
- `assets/images/` and `assets/icons/` for portfolio visuals and branding
